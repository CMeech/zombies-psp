## Runtime and packaging gates

Native interactive and headless commands:

```sh
cargo run --release -p openstrike -- --maps-dir "$OPENSTRIKE_MAPS" --auto-quit 5
cargo run --release -p openstrike -- --maps-dir "$OPENSTRIKE_MAPS" --script walk --screenshot out/walk
```

The deterministic `walk` scenario passed completely using the ignored local data. It verified settle, run, viewmodel stability, wall sliding, and jumping, and wrote `out/baseline/walk.settle.png` and `out/baseline/walk.run.png`. The loader warned that eight texture names were unresolved: `+0~fifties_lgt2`, `+a~fifties_lgt2`, `aaatrigger`, `black`, `clip`, `generic011`, `sky`, and `white`.

The native interactive auto-quit smoke did not launch. The desktop host found `dist/pocket/psp/openstrike.js`, but PocketJS rejected it with `native target mismatch (bundle=psp, host=desktop)`. The documented `bun run build:ui` produces the PSP bundle, and `desktop` is not a recognized Pocket target at this revision. This is a verified upstream baseline divergence, not a downstream gameplay change.

PSP commands:

```sh
bun scripts/psp.ts
bun scripts/psp.ts --package
```

The release EBOOT build and Memory Stick package both passed:

- `crates/openstrike-psp/target/mipsel-sony-psp/release/EBOOT.PBP`: approximately 3.4 MiB.
- `dist/PSP/GAME/OpenStrike/EBOOT.PBP`: byte-identical to the build artifact.
- EBOOT SHA-256: `08833e24ba8510905c894672b7d9389a2bd2eee8627cdf9f786b87b8cfc9f865`.
- Cooked `dist/maps/de_dust2.p3d`: approximately 3.6 MiB; structural verification passed with 1,455 leaves, 1,201 visleaves, and 20/20 spawns.

The cook used placeholders for the same eight unresolved textures recorded above.

PPSSPP command:

```sh
bun scripts/e2e-psp.ts
```

`PPSSPPHeadless` is installed at a non-default path and was selected with `PPSSPP_HEADLESS=/Users/cash/repos/ppsspp/Build/PPSSPPHeadless`. The complete journey produced every expected raw frame: spawn 4/4, walk 44/44, and fire 12/12. All five selected PNGs were non-degenerate but failed byte-exact comparison with the checked-in goldens. The installed PPSSPP revision differs from the pinned revision; unresolved placeholder textures are another environmental difference. No golden update was performed and no physical-hardware result is claimed.
