# Pocket Survival Project

This downstream is planning an original, free, community-led round-based survival FPS for PSP homebrew on the pinned OpenStrike baseline. `pocket-survival` remains a temporary working name.

The project constraints, milestone roadmap, architecture decisions, milestone contracts, and research live in this directory. The repository-root `README.md` is retained from the selected OpenStrike baseline until downstream product documentation replaces it deliberately.
