# Pocket Survival Project

This downstream is planning an original, free, community-led round-based survival FPS for PSP homebrew on the pinned OpenStrike baseline. `pocket-survival` remains a temporary working name.

The project constraints, milestone roadmap, architecture decisions, research, and handoff notes live in this directory. The repository-root `README.md` is intentionally retained from the selected OpenStrike revision while Milestone 2 reproduces the unmodified baseline.

Start with [ROADMAP.md](ROADMAP.md) and [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md).

New Mac setup: [macos-setup.md](macos-setup.md).
